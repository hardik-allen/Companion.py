# Saarthi — companion.py

Landing page for Saarthi, companion.py's voice agent that reads a business's own
screens and controls and acts on them directly. Built with Next.js (App Router)
and Tailwind CSS.

Live demo of the underlying tech: [BharatBank](https://bharat-bank.onrender.com),
a fictional digital bank.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```

## Stack

- Next.js 16 (App Router, Turbopack)
- Tailwind CSS 4
- TypeScript
